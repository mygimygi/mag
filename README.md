# MAGNET POP : 전자석 대작전

초등학교 5~6학년을 위한 2D 고정 화면 아케이드 액션 게임입니다.
전자석으로 철 몬스터를 끌어당겨 흡수하고(전류 ON), 버튼을 놓아 발사합니다(전류 OFF).

## 실행 방법

- **가장 간단한 방법**: `index.html` 을 브라우저(Chrome, Edge, Safari)로 엽니다. 인터넷 연결이 필요 없습니다.
- **태블릿 / 학교 서버**: 폴더 전체를 웹 서버에 올리고 `index.html` 주소로 접속합니다.
  한 번 접속하면 서비스 워커가 파일을 저장해 이후에는 오프라인에서도 실행됩니다. 홈 화면에 추가할 수 있습니다.
- 로컬 서버 예: `python3 -m http.server 8000` 실행 후 `http://localhost:8000`

## 조작

| | PC | 태블릿 |
|---|---|---|
| 이동 | ← → 또는 A D | 왼쪽 조이스틱 |
| 점프 | SPACE, W, ↑ (↓+점프: 발판 아래로) | 조이스틱을 위로(대각선 포함) 밀기 |
| 전류 ON · 흡수 | Z 또는 J 누르고 있기 | 전자석 버튼 누르고 있기 |
| 전류 OFF · 발사 | Z 또는 J 놓기 | 버튼에서 손 떼기 |
| 일시정지 | ESC | 화면 위 Ⅱ 버튼 |

## 휴대폰·태블릿

- 터치 기기에서는 왼쪽 아래에 둥근 8방향 조이스틱(좌우 이동, 위·대각선 위로 밀면 점프(다시 점프하려면 손잡이를 되돌렸다가 다시 올림), 아래로 밀면 발판 아래로), 오른쪽 아래에 전자석 버튼이 나옵니다.
- 점수와 스테이지 표시 사이의 작은 버튼으로 전체 화면을 켜고 끌 수 있습니다.
- 휴대폰을 세로로 들고 있으면 게임 전체가 90도 돌아가 화면을 가득 채웁니다(화면 회전 잠금 상태에서도 가로로 돌려 플레이 가능).
- 처음에는 메뉴와 스테이지 1에 필요한 이미지만 받고, 각 스테이지의 배경과 몬스터 이미지는 그 스테이지를 시작할 때 받습니다.
- 작은 화면에서는 글자를 키우고, 과학 교실은 한 장씩 넘겨 봅니다. 2초 이상 45FPS 아래로 떨어지면 그리는 해상도를 한 단계씩 낮춥니다.
- 첫 번째 터치·클릭·키 입력 때 전체 화면으로 바뀝니다(브라우저 규칙상 입력 없이 자동 전환은 불가능). 설정에서 끌 수 있습니다.
  iPhone 의 Safari 처럼 전체 화면 기능이 없는 브라우저에서는 홈 화면에 추가하면 전체 화면으로 실행됩니다.

- 웹 주소로 서비스할 때는 항상 최신 파일을 먼저 받고(저장된 파일은 오프라인일 때만 사용), 제목 화면 오른쪽 위에 버전 번호가 보입니다.
  새 버전을 올릴 때는 `node tools/version.js <번호>` 로 버전을 올립니다.

## 구성

- 일반 스테이지 15개(5개 월드 × 3) + 16번째 최종 보스 스테이지(마그넷 타이탄, 3단계 전투)
- 스테이지 9에는 중간 보스 컴퍼스 킹이 등장합니다(전자석으로 나침반 바늘을 어지럽혀 기절시킨 뒤 공격).
- 몬스터 7종(철구, 철갑 로봇, 고철 슬라임, 자석 벌레, 철제 박쥐, 철판 골렘, 대형 철제 로봇)
  + 스테이지 12의 비자성 물체 3종(나무 상자, 플라스틱 오리, 알루미늄 캔 — 전자석에 끌려오지 않음)
- 업그레이드는 정확히 두 가지, 각각 3단계까지: 건전지 1→2→3개, 에나멜선 10→20→30회
  - 강화 재료는 스테이지 6 / 9 / 12 를 처음 클리어할 때 각각 한 단계씩 올릴 수 있도록 지급됩니다.
  - 3단계 강화는 다른 부품이 2단계 이상일 때 가능합니다(가능한 조합: 1+10, 2+10, 1+20, 2+20, 3+20, 2+30, 3+30).
  - 스테이지 13~16 은 점수만 지급합니다.
- 과학 교실(6가지 원리, 그림 포함)과 최종 클리어 후 과학 퀴즈 6문제
- 진행 상황·업그레이드·설정은 브라우저 localStorage 에 자동 저장됩니다(설정 → 처음부터 다시로 초기화).
- 난이도는 쉬움과 보통 두 가지입니다. 처음 `게임 시작`을 누를 때 고르고, 설정에서 바꿀 수 있습니다. 쉬움은 박쥐가 나오지 않고 모든 몬스터가 10% 느립니다.
- 하트는 5개입니다. 같은 스테이지에서 게임 오버가 되면 다음 도전에서 몬스터가 조금 느려집니다(1회당 5%, 최대 15%).
- 스테이지마다 4~9번의 웨이브로 몬스터 9~34마리가 나옵니다. 몬스터가 나타나는 자리는 웨이브가 시작될 때 주인공에게서 떨어진 곳으로 정해집니다.
- 발판 종류: 일반, 움직이는 발판(좌우·상하), 사라지는 구름, 밟으면 떨어지는 나무 다리, 스프링 발판, 컨베이어 벨트
- 철 몬스터는 자기장에 닿으면 잠깐 버티다가(무거울수록 오래, 전자석이 강할수록 짧게) 끌려옵니다.
- 전자석은 강화할수록 겉모습이 달라집니다. 몸체가 회색 → 파랑 → 보라 → 빨강 → 진홍으로 바뀌고 건전지와 코일 색도 진해지며,
  금색 장식과 보석, 반짝임, 붉은 기운이 더해집니다. 자기장은 몬스터가 잘 보이도록 옅은 원뿔과 또렷한 고리로만 그립니다. 강화하면 고리 색이 조금 바뀌고(파랑 → 보라 → 주황) 코일 단계만큼 고리가 늘어납니다.
  강화한 전자석 주변에는 옅은 빛이 돌고, HUD 에 강화 단계가 별로 표시됩니다.
- 마그넷 타이탄: 가슴의 나침반 바늘이 전자석 쪽으로 돌아가고, 주먹 2~3개를 주인공이 서 있던 자리로 포물선으로 던집니다(던진 뒤에는 방향을 바꾸지 않음, 날아가는 시간 1.6초).
- 점프 속도는 처음 값(885)보다 10% 높은 974 입니다(최고 높이 약 215px).
- 상점: 스테이지를 클리어하면 항상 상점 문제가 먼저 나옵니다(건너뛸 수 없음). 순서는 클리어 → 문제 → (맞히면) 아이템 하나 고르기 → 결과 창입니다.
  결과 창에는 `다음 스테이지`와 `전자석 강화` 버튼이 있습니다. 문제를 틀리면 상점 없이 결과 창으로 넘어갑니다. 최종 스테이지는 엔딩으로 갑니다.
  - 문제는 처음에는 1~5번 순서대로, 다섯 문제가 모두 나온 뒤에는 매 바퀴마다 순서를 섞어 다섯 문제를 한 번씩 냅니다(`js/config.js` 의 `MP.SHOP_Q`).
  - 문제를 맞히면 보상으로 아이템 4종 중 하나를 골라 받습니다(코인 필요 없음): 하트(하트 1개 추가), 전자 보호막(25초 동안 공격 막기), 스피드 부츠(25초 동안 이동 속도 1.45배), 초강력 자석(25초 동안 흡수 범위 1.5배).
  - 아이템은 다음에 시작하는 스테이지에서 시작과 동시에 자동으로 쓰이고, 그 스테이지를 다시 시작하면 남아 있지 않습니다.
- 캐릭터 꾸미기: 성별, 머리 모양 5종, 머리 색 6종, 눈 크기 3종, 피부색 5종, 옷 색깔 7종, 모자 5종, 선글라스.
  처음 `게임 시작`을 누르면 열리고, 메뉴와 스테이지 선택 화면에서 언제든 다시 바꿀 수 있습니다.
- 상점을 마치면 `다음 스테이지`와 `전자석 강화` 버튼이 있는 결과 창이 나옵니다. 재료가 모자라면 강화 버튼을 눌렀을 때 부족한 개수를 알려 줍니다.

## 그래픽 에셋에 대하여

이 개발 환경에는 이미지 생성 도구가 없어서, 모든 캐릭터·몬스터·보스·배경·플랫폼을
**직접 그린 벡터 일러스트(SVG 리그)** 로 제작한 뒤 투명 배경 PNG 스프라이트 시트로 렌더링했습니다.
게임 실행 중에는 Canvas 도형이 아니라 이 PNG 스프라이트 시트의 프레임을 그립니다
(자기장 파동, 충격파, HUD 틀 같은 이펙트·UI 만 Canvas 로 그립니다).
참고 이미지처럼 손으로 채색한 페인팅 질감은 아니며, 깔끔한 카툰 벡터 스타일입니다.

- `assets/img/hero.png` 주인공(기본 모습) 11개 동작 50프레임 (대기, 걷기, 달리기, 점프, 착지, 전자석 작동, 흡수, 발사, 피격, 승리, 사망)
- `assets/img/weapon.png` 전자석 18종 (건전지 1~3개 × 코일 10/20/30회 × 전류 ON/OFF)
- `assets/img/m_*.png` 몬스터 10종 × 21프레임 (대기, 이동, 점프, 공격, 피격, 흡수, 제거)
- `assets/img/king.png`, `titan.png`, `parts.png` 보스와 부품, `fx.png` 아이콘·이펙트
- `assets/img/bg1~16.jpg` 스테이지별 배경, `plat_*.png` / `ground_*.png` 월드별 플랫폼 타일
- 주인공과 전자석의 리그는 `js/heroart.js` 에 있습니다. 기본 모습은 위 PNG 를 쓰고, 캐릭터를 꾸미면 같은 리그로
  스프라이트 시트를 브라우저에서 다시 그려 사용합니다(그리기에 실패하면 기본 PNG 로 돌아갑니다).
- `assets/img/plat_cloud|spring|conveyor|wood.png` 특수 발판
- 원본 아트 코드와 빌드 스크립트: `tools/art/*.js`, `tools/build.js` (`node tools/build.js` 로 다시 생성, Playwright 필요)

사운드는 Web Audio API 로 합성한 효과음과 직접 작곡한 배경 음악이며 음원 파일이 없습니다.
글꼴은 Jua (SIL Open Font License, `assets/fonts/OFL-Jua.txt`).

## 코드 구조

| 파일 | 역할 |
|---|---|
| `js/config.js` | 스테이지·몬스터·업그레이드 수치, 과학 교실·퀴즈 내용 |
| `js/game.js` | 게임 로직(물리, 전자석 흡수/발사, 몬스터 AI, 웨이브) — 그리기 없음 |
| `js/bosses.js` | 컴퍼스 킹, 마그넷 타이탄 |
| `js/render.js` | 렌더링 전용(게임 상태를 읽기만 함) |
| `js/ui.js` | 메뉴, 스테이지 선택, 업그레이드, 과학 교실, 퀴즈 화면 |
| `js/main.js` | 16:9 화면 맞춤, 1/120초 고정 시간 간격 루프 |
| `js/input.js`, `audio.js`, `save.js` | 키보드·멀티터치 입력, 사운드, 저장 |
